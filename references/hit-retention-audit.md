# 完播与互动审核：导演、平台与观众视角

当用户要求“爆款”“高完播”“前 3 秒抓人”“引发评论、转发、点赞”，先执行本审核，再决定是否重构故事。它优化的是故事和成片的传播条件，不承诺任何真实平台指标。

前 3 秒、核心冲突、持续留存或平台适配任一低于 4 分时，不直接润色全文，先给 2–3 个开场 / 结构修复方向。

## 一、前 3 秒钩子

前 3 秒不是“画面很大”或“声音很响”，而是让观众立刻产生继续观看的理由。优先在 0–3 秒内完成以下链条：

1. **第一眼异常**：出现一个不该出现的画面、动作、关系或结果。
2. **立刻的代价**：观众知道如果不处理，会失去什么、暴露什么或来不及什么。
3. **未完成的问题**：画面停在一个必须看下去才能回答的选择、追逐、秘密或后果上。

有效钩子至少命中两项：

- **结果先行**：先看到不可逆的结果，再追问它是怎么发生的。
- **矛盾同框**：两个不能同时成立的事实同时出现。
- **迫近选择**：主角必须在两个都要付代价的选项中立刻选一个。
- **身份落差**：观众看到角色表面身份与真实行为不一致。
- **熟悉刺痛**：把观众熟悉的生活困境压缩成一个具体动作或瞬间。
- **视觉异常**：一个只属于这个故事的物件、空间规则或动作引发问题。

不要把片名、品牌口号、背景介绍、人物履历、漂亮空镜、泛泛哭喊放在钩子之前，除非它们本身就是矛盾或悬念。

### 前 3 秒自检

- 截掉声音，只看画面，是否仍然想知道接下来发生什么？
- 截掉画面，只听声音，是否仍然存在具体问题或选择？
- 不解释背景，观众是否能猜到主角当下的欲望、危险或损失？
- 钩子是否来自故事核心，而不是与后面无关的噱头？
- 如果把主角和题材替换掉，钩子是否仍然完全成立？如果是，说明还不够独特。

## 二、留存结构

用“承诺 → 兑现一部分 → 改变问题 → 提高代价 → 再次改写理解”的链条推进，不要连续使用同一种刺激。

### 短视频相对节奏

- **0–3 秒**：钩子，只让观众产生一个明确问题。
- **3–10 秒**：主角、目标、即时损失和观看承诺变得可理解。
- **10–30 秒**：第一次行动与第一次代价，证明故事不是只会吊胃口。
- **中段**：至少一次信息、关系、目标或价值判断的变化，让观众重新理解前面。
- **最后 10%–20%**：兑现核心承诺，并留下情绪余波、立场冲突或可转述的意义。

时长更长时，不是机械增加镜头，而是增加新的选择和后果。每个场景至少改变目标、代价、信息、关系、规则或主角主动性中的一项。

### 留存失败信号

- 只有开头有噱头，中间回到普通背景介绍。
- 每次升级都只是更大的雨、更响的音乐、更快的剪辑或更严重的受伤。
- 观众已经猜到结局，却没有新的信息或关系变化。
- 中点只是“找到了 / 看到了 / 到达了”，没有改变故事问题。
- 结尾才突然告诉观众真正的主题、身份或规则。

## 三、五类创作者视角

| 视角 | 首要问题 | 必须看到的结果 |
| --- | --- | --- |
| 爆款短剧导演 | 观众为什么在 3 秒后还不划走？ | 目标清楚、代价迫近、节点持续升级、每段有未完成问题 |
| TVC 导演 | 能否用一个动作或画面让人记住？ | 视觉概念统一、情绪瞬间明确、节奏精确、品牌不破坏戏剧 |
| 品牌广告导演 | 品牌为什么必须出现在这个故事里？ | 品牌参与冲突或解决，品牌价值变成角色行为而非口号 |
| 故事片 / 剧情片导演 | 这个选择是否改变了人物和因果？ | 人物主动、冲突复杂、反转有铺垫、结尾有余韵 |
| 抖音 / 小红书 / 视频号观众 | 我为什么看、为什么要说、为什么要发给别人？ | 即时理解、生活共鸣、可表达立场、具有社交转发对象 |

## 四、平台观众视角

平台不是固定公式，要先选一个主平台，再做针对性适配。不要把三个平台的习惯平均混成一条没有重点的内容。

### 抖音

- 依赖第一眼和第一句迅速建立问题。
- 适合高概念、强选择、清晰目标和连续变化。
- 结尾应有明确兑现或反差，不能只留下“未完待续”的空吊胃口。
- 评论触发来自选择题、价值冲突、身份代入或出乎意料的后果。

### 小红书

- 观众更容易被“这就是我 / 我身边的人”触发，而不是被纯粹吵闹留住。
- 细节、关系、审美和生活真实感会影响停留与收藏。
- 评论点适合具体经验、边界讨论、情感判断和身份共鸣。
- 转发理由常是“发给某类人看”，但必须先有真实而准确的情绪命中。

### 视频号

- 更重视完整、顺畅、可转述的情绪体验和社交传播。
- 家庭、亲情、关系、时代经验或普遍处境容易形成转发语境，但不能只靠煽情。
- 结尾要给观众一个能说给别人听的完整判断、画面或情绪回响。

## 五、评论、转发与点赞的真实触发器

### 评论

评论不是靠“你怎么看”强行索取，而是让观众有必要表达：

- 两个立场都合理，但不能同时满足。
- 主角的选择会让观众分成两派。
- 观众能把自己的经历投射进具体细节。
- 结局留下有根据的解释空间，而不是信息缺失。
- 某个行为触碰了关系边界、道德边界或现实规则。

输出时说明：观众可能争论的两种立场分别是什么，以及故事提供了哪些证据支持它们。

### 转发

观众通常转发给“某一个具体的人”或“某一类经历相似的人”。审核时必须回答：

- 他会转发给谁？
- 他想借这个故事表达什么？
- 故事中有没有一句可转述的判断，或一个能代表这类人的动作？

不要只写“很感人，所以会转发”。

### 点赞

点赞往往来自即时情绪兑现：爽、痛、暖、惊、敬佩、被理解或被说中。必须指出具体情绪落点和触发画面。

## 六、修复方式

当审核分数不足时，按影响顺序处理：

1. **先改前 3 秒**：提供 3 个不同类型的冷开场，每个说明异常、代价、未解问题和后续如何兑现。
2. **再改核心冲突**：让至少两个合理目标互相冲突，并说明主角必须牺牲什么。
3. **再改中段留存**：给每个关键节点增加新的信息、关系、规则、代价或主动选择。
4. **再改反转与结尾**：让反转重新解释前文，让结尾兑现承诺并留下可争论的立场。
5. **最后做平台版本**：只改变开场速度、信息顺序、画面重点和结尾表达，不擅自改变题材、主角和核心创意。

每个修复方向必须写清楚：

- 改变什么；
- 保留什么；
- 增加什么代价；
- 会提高哪一类观众行为；
- 有什么副作用或风险。

## 七、产品宣传片的因果门槛

当内容是产品宣传片、品牌宣传片或 TVC，不能把产品当作普通道具。必须先写出：

> 人物处境 → 产品能力 → 关键行动 → 剧情改变 → 主题落点

### 四项测试

- **替换测试**：换成任意同类产品后，故事是否仍然成立？如果几乎不变，产品没有进入故事发动机。
- **删除测试**：删掉产品后，主角是否仍能用同样方式完成目标？如果可以，产品只是道具。
- **证据测试**：产品能力是否通过真实动作、使用场景、界面或结果被看见？不能只靠旁白宣称。
- **真实测试**：产品外观、Logo、接口、CPU、参数和功能是否来自已确认的品牌资料？未确认时不写精确承诺。

产品至少要在“问题出现、关键行动、结果兑现”三个节点承担剧情功能。任何一项测试失败时，先给出产品因果重构方向，再写完整剧本。
