# 故事兴趣审核：钩子、冲突与反转

当用户说故事无聊、普通、平淡、没有钩子、冲突不够或反转不明显时，先审核再重写。不要用更大的灾难、更强的形容词或更悲惨的背景掩盖结构问题。

## 审核输出

```markdown
审核结论：
故事当前最弱的三个点：

| 维度 | 分数（1–5） | 剧情证据 | 观众感受 | 修复方向 |
| --- | ---: | --- | --- | --- |
| 钩子 |  |  |  |  |
| 核心冲突 |  |  |  |  |
| 升级 |  |  |  |  |
| 反转 |  |  |  |  |
| 主角主动性 |  |  |  |  |
| 视觉独特性 |  |  |  |  |
| 模板感 |  |  |  |  |

必须保留：
可以改变：
禁止改变：

建议先选择的修复方向：
1. ...
2. ...
3. ...
```

分数不是审美结论，而是决定是否需要重做结构的信号。钩子、核心冲突或反转低于 4 分时，不直接全文润色。

## 1. 钩子审核

前 1–3 个剧情节点至少满足两项：

- 具体异常：某件事不该发生，却发生了。
- 具体危险：主角必须在有限时间内行动。
- 具体欲望：主角想得到一个清晰且有代价的东西。
- 具体矛盾：两个合理目标无法同时完成。
- 未解问题：观众会自然追问“为什么会这样”或“接下来会怎样”。
- 独特承诺：这个故事的看点不是换一个题材也能成立的通用事件。

避免以下伪钩子：

- 先用大量背景介绍再进入事件。
- 只写“暴雨、爆炸、尖叫、神秘声音”但没有具体选择。
- 用一句主题金句代替戏剧问题。
- 只把角色写得很惨，却没有正在发生的行动。

## 2. 冲突审核

至少建立两层不同性质的冲突，并让它们互相加压：

| 冲突层 | 要回答的问题 | 常见有效形式 |
| --- | --- | --- |
| 外部阻力 | 什么阻止主角完成目标？ | 空间、制度、对手、时间、资源 |
| 内部缺陷 | 主角自己怎样让事情变糟？ | 逃避、控制欲、骄傲、误判、执念 |
| 关系冲突 | 谁和主角的目标不完全一致？ | 不信任、隐瞒、背叛、价值分歧 |
| 价值选择 | 两个选择为什么都要付出代价？ | 救谁、牺牲什么、是否说真话 |

只增加环境危险，不改变人物选择，不算有效升级。

## 3. 升级审核

连续三个节点不能只是同一障碍变得更强。每次升级至少改变一项：

- 目标：主角想要的东西变了。
- 代价：失败后会失去更重要的东西。
- 信息：观众或主角重新理解了之前的事实。
- 关系：盟友变成阻力，或敌对关系被迫合作。
- 规则：原本可行的方法不再可行。
- 主动性：主角的选择制造了新的问题。

## 4. 反转审核

反转不是“突然揭露一个秘密”，而是让前面已经出现的事实获得新的意义。

### Midpoint

至少完成一项：

- 目标从“得到某物”变成“保护某人”或“阻止某事”。
- 盟友、对手或主角的身份关系被重新理解。
- 假胜利变成更大的责任。
- 主角原本的解决方案证明会伤害真正重要的东西。

### All Is Lost

- 最好由主角的错误判断或逃避造成。
- 必须比 Midpoint 更深，不能只是再次失败。
- 应该损失关系、信任、机会、身份、目标或不可替代的东西。

### Finale

- 解决方案必须来自前文铺垫。
- 主角必须主动选择，而且至少放弃一项重要东西。
- 结局不能只靠配角、巧合、突然能力或新信息完成。

## 5. 反模板审核

发现以下模式时，必须标记并提出替代方案：

- 工具人配角：只负责提供手电、绳子、线索或鼓励。
- 主题台词：角色直接说出故事要表达的道理。
- 灾难堆叠：暴雨、停电、没电、地滑、受伤依次出现，但人物关系没有变化。
- 假反转：只是发现目标、到达地点或看到秘密。
- 方便合作：主角一接受帮助，所有人立刻配合并成功。
- 标准升华：雨停、天亮、拥抱、掌声直接代表人物改变。
- 通用场景：删掉片名和角色名字后，故事仍然可以换成任何题材。

## 6. 修复方向

审核完成后，优先给出 2–3 个方向，不直接替用户决定：

- **现实压力型**：让职业、金钱、时间或身份真正阻碍主角。
- **关系对抗型**：让帮助主角的人同时拥有相反目标。
- **价值困境型**：让主角无法同时保护两个重要对象。
- **信息重构型**：让前文事实在中点之后产生新含义。
- **类型升级型**：在保留原题材的前提下，明确转向悬疑、黑色幽默、惊悚、荒诞或社会观察。

每个方向必须说明：改变什么、保留什么、代价是什么、为什么会更有吸引力。
