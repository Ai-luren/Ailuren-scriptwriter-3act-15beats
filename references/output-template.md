# 默认输出模板

根据用户给出的素材，按以下顺序输出。资料不足时做最少必要补充，并在末尾标注“创作假设”。

## 1. 故事核心

- 一句话故事 Logline
- 核心主题命题
- 故事类型、媒介与建议时长

## 2. 人物发动机与人物弧光

- 主角：外在目标、内在需求、错误认知/缺陷、风险
- 关键角色：与主角的关系及剧情功能
- 人物弧光：初始状态 → 压力 → 认识改变 → 最终选择 → 结束状态

## 3. 三幕式完整结构

### 第一幕｜建立

建立人物、世界、关系、欲望与缺陷；完成催化事件和第一转折点。

### 第二幕｜对抗

展开主角的行动、B 故事与核心卖点；完成中点升级、危机逼近和一切尽失。

### 第三幕｜解决

完成灵魂黑夜、进入第三幕、高潮行动与结尾画面对照。

## 4. 15 Beats 节拍表

使用 `references/beat-sheet.md` 的 15 个剧情功能逐项映射。每个 Beat 写清楚：发生了什么、改变了什么、如何推进下一步。

## 5. 场景级剧情大纲

每个场景至少包含：

- 场景编号、内/外景、地点、时间
- 可见动作与人物状态
- 场景目的或转折
- 必要对白或声音信息
- 与下一个场景的因果关系

优先使用“因为 / 所以 / 但是”推进，避免连续使用“然后”。不改变局势或人物的场景应合并或删除。

## 6. 结构诊断

检查主角目标、风险、第一幕进入、第二幕升级、中点换规则、最低点、高潮主动性、前后画面对照，以及是否存在可以删除的场景。

## 7. 创作假设

仅列出为补齐因果而新增的关键设定，不重复用户已经明确给出的内容。
